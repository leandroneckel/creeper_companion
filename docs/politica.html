What is signed

Only the Windows release files built from the source code in this repository: CreeperCompanion-Setup.exe (installer) and CreeperCompanion.exe (application), published on the releases page. Signed releases are built automatically from a tagged commit on GitHub-hosted runners (GitHub Actions), and every signing request is approved manually by an approver listed below.

Privacy policy

This program will not transfer any information to other networked systems unless specifically requested by the user or the person installing or operating it.

  • The only network access is the update check, and it is opt-in: the installer has a checkbox for it and, without the installer, the program asks on first run. When enabled, it asks the GitHub Releases API for the latest version every 6 hours, and downloads a new version from GitHub only when the user clicks "Update". It can be turned off at any time in Settings. These requests go to GitHub and are covered by the GitHub Privacy Statement.
  • No telemetry, no analytics, no ads and no accounts.
  • The pet's progress and settings are stored only on the user's computer (%APPDATA%\CreeperCompanion on Windows, ~/.config/creeper-companion on Linux). The uninstaller offers to delete them.

Privacidade

Este programa não envia nenhuma informação para outros sistemas na rede, a não ser que o usuário, ou quem instala ou usa o programa, peça.

  • O único acesso à internet é a procura de versão nova, e só se você deixar: o instalador tem uma opção pra isso e, sem instalador, o creeper pergunta na primeira vez que abre. Ligada, ela pergunta ao GitHub qual é a versão mais nova a cada 6 horas, e só baixa quando você clica em "Atualizar". Dá pra desligar a qualquer hora em Configurações. Esses pedidos vão para o GitHub e seguem a declaração de privacidade do GitHub.
  • Sem telemetria, sem estatísticas de uso, sem propaganda e sem contas.
  • O progresso do creeper e as configurações ficam só no seu computador (%APPDATA%\CreeperCompanion no Windows, ~/.config/creeper-companion no Linux). O desinstalador pergunta se você quer apagar.

Projeto de fã, sem fins comerciais. Não é oficial nem associado à Mojang Studios ou à Microsoft.
